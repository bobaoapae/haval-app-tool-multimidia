# License Change — MIT → AGPL-3.0-or-later

**Effective date:** 2026-08-18
**Previous license:** MIT
**New license:** GNU Affero General Public License v3.0 or later (AGPL-3.0-or-later)

## English

As of the date above, HavalShisuku is relicensed from the MIT License to the GNU Affero General Public License v3.0 or later (AGPL-3.0-or-later).

**Why:** to keep improvements to this project shared back with the community. Under MIT, anyone could take the code, close it up, or wrap it into a paid/closed product or hosted service without giving anything back. AGPL-3.0 requires that redistributed copies (modified or not) stay open under the same terms, and — unlike plain GPL — also covers the case where a modified version is run as a network service that other people use remotely (AGPLv3 §13): the operator must offer those users the corresponding source too.

**What this means going forward:**
- Anyone who redistributes HavalShisuku (modified or not) must do so under AGPL-3.0-or-later and make the corresponding source code available.
- If a modified version is ever run as a network service/backend that other people interact with remotely, the operator must also offer those users the corresponding source (AGPLv3 §13). Neither MIT nor plain GPLv3 require this.
- Commercial use remains allowed — copyleft governs how the source is redistributed, not whether it can be used commercially.

**What this means for code obtained before this date:** Copies of the code already distributed under the MIT License (including existing forks) remain validly licensed under MIT to whoever received them — MIT grants are irrevocable. This change applies to the codebase from this point forward; it does not revoke MIT rights already granted.

**Contributor consent:** Copyright in each contribution is held by its author. Relicensing the project therefore required the agreement of every contributor with non-trivial contributions. The following contributors agreed to relicense their contributions under AGPL-3.0-or-later:

## Português

A partir da data acima, o HavalShisuku deixa de ser licenciado sob MIT e passa para a GNU Affero General Public License v3.0 ou posterior (AGPL-3.0-or-later).

**Por quê:** para manter as melhorias feitas neste projeto compartilhadas com a comunidade. Sob MIT, qualquer pessoa podia pegar o código, fechá-lo, ou embutir num produto pago/fechado ou serviço hospedado sem devolver nada. A AGPL-3.0 exige que cópias redistribuídas (modificadas ou não) continuem abertas sob os mesmos termos e, diferente da GPL comum, também cobre o caso de uma versão modificada rodar como um serviço de rede usado remotamente por outras pessoas (AGPLv3 §13): quem opera esse serviço também é obrigado a oferecer o código-fonte correspondente a esses usuários.

**O que muda daqui pra frente:**
- Quem redistribuir o HavalShisuku (modificado ou não) deve fazer isso sob AGPL-3.0-or-later e disponibilizar o código-fonte correspondente.
- Se uma versão modificada rodar como serviço/backend de rede usado remotamente por outras pessoas, quem opera esse serviço também é obrigado a oferecer o código-fonte correspondente (AGPLv3 §13). Nem o MIT nem a GPL comum exigem isso.
- Uso comercial continua permitido — o copyleft rege como o código-fonte é redistribuído, não se ele pode ser usado comercialmente.

**O que isso significa pro código obtido antes desta data:** Cópias do código já distribuídas sob MIT (incluindo forks existentes) continuam validamente licenciadas sob MIT para quem já as recebeu — a concessão MIT é irrevogável. Essa mudança vale a partir de agora; ela não revoga direitos MIT já concedidos.
